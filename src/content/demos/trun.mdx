Just a small raymarching game I originally made to practice and experiment with the technique, after having some fun building a [software raymarcher](/demos/rm-racer).

In this mini game, you control a spaceship and must move forward while avoiding obstacles, using the arrow keys or WASD. Collect crystals along the way to gain speed and extra time, and try to travel as far as possible before the timer runs out.

I find the idea pretty cool, even if it's probably nothing new, the inspiration actually came from a mix of minecraft's dropper maps and the atmosphere of some activities in saints row 3/4

I might eventually update it with more varied challenges and find something to do with the crystals you collect outside of runs, but only if I can manage not to get distracted by other projects first! :3

## More infos

To make this mini game I first made a "toolkit" written in C3 to make creating scenes in GLSL as easy as possible. It's compatible with everything from WebGL 1 to OpenGL 4.x and includes some optimizations originally designed for my software raymarcher.

You can find the source code here: https://github.com/Bigfoot71/rlm-c3
