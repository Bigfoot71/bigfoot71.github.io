X-Arena was built in six days for the **raylib 6.x Game Jam**, written in [C3](https://c3-lang.org/).

It's a wave-based arena shooter where enemies swarm in from all sides of a hexagonal arena.

The game revolves around perks: defeated enemies drop orbs, and collecting them unlocks a random perk.
You can carry up to six at a time, then new perks replace old ones.

I also took this opportunity to experiment with and learn the C3 programming language.
Probably not the smartest choice for a game jam, but I'm pretty happy with how it turned out.
