Raze Protocol is an abandoned project, for now, where the idea was to make a shooter in a destructible voxel world, but where the world only exists within a radius around players and bots.

Although there is a mode with procedurally generated levels, the game also features a map editor and even a Lua scripting system to create your own game modes.

The project is written in Odin using raylib and my own engine [r3d](/projects/r3d/).

It was also abandoned because I wasn't satisfied with the gameplay and mechanics it offered.
I'm currently working on a similar idea, but with gameplay that offers much more freedom ^^
